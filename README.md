# Volley-Buddy

Strand-Volleyball als PWA mit Wackelpudding-Figuren (HTML/Canvas/JS, offline-fähig).

- 1:1 lokal (P1: A/D/W + Strg links, P2: Pfeile + Strg rechts)
- 2:2 (zwei Spieler gegen 2 KI)
- 1:1 gegen KI (WASD oder Pfeiltasten)
- Highscore im Browser (localStorage)

Lokal testen: `python3 -m http.server` und http://localhost:8000 öffnen.

Live: https://dixi1989.github.io/volley-buddy/
